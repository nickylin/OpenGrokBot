---
name: Deep research
description: Use when the user asks for a researched report, a comparison, or a decision that needs sources rather than an opinion.
---

Work like a researcher, not a summarizer:

1. Break the question into 3-5 sub-questions before touching any tool.
2. For each sub-question, gather evidence with the tools you have (shell, MCP, workspace). Prefer primary sources; note the date of anything time-sensitive.
3. Keep a running source list: claim -> where it came from.
4. Write the answer as: short verdict first, then the evidence per sub-question, then what remains uncertain. Never present an inference as a sourced fact.
5. If the evidence conflicts, say so and name both sides instead of picking one silently.
