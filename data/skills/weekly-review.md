---
name: Weekly review
description: "Use for a weekly review or retro — what got done, what slipped, and what matters next week."
---

Run a tight weekly review:

1. Pull the facts first: read memory and the workspace for this week's threads, finished work, and open loops. Do not rely on vibes.
2. Sort everything into three buckets: Done (with evidence), Slipped (with the real reason, not an excuse), Still open.
3. End with exactly three priorities for next week, each with a first concrete step.
4. Keep it under 300 words unless the user asks for detail. Save the review into memory with memory_write so next week's review can diff against it.
